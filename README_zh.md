## 痛点

所有水下ROV、云台摄像头、机械臂、旋转平台都需要**滑环**来传输动力和信号。滑环：

- **维护成本高** — 电刷磨损，接触持续退化
- **不可靠** — 信号噪声增大，连接不稳定
- **昂贵** — 品质滑环单价$50–500+
- **体积大** — 占用紧凑装配中的宝贵空间

这是ROV、机器人、安防、工业自动化领域的**十亿级痛点**。

## 方案

将所有线缆穿过旋转关节的**空心轴心**。无滑动触点。无电刷。零磨损。

| | 滑环 | 轴心走线（本方案） |
|---|---|---|
| 磨损 | 电刷摩擦，持续退化 | **无** — 线缆静止 |
| 维护 | 定期更换电刷 | **零** |
| 信号质量 | 滑动接触产生噪声 | **干净稳定** |
| 成本 | $50–500+/个 | **标准线缆+连接器** |
| 寿命 | 受电刷磨损限制 | **仅受线缆疲劳限制** |
| 旋转 | 连续360° | **连续360°** |
| 防水 | 密封复杂 | **波纹管密封（工业成熟方案）** |

## 核心设计特征

1. **轴心走线** — 所有动力和信号线穿过空心轴，无滑环、无换向器、零旋转触点。支持电力、模拟、数字、光纤。

2. **波纹管密封** — 工业级波纹管在旋转关节处提供防水密封，汽车/航空/重机械领域成熟方案，远比柔性膜和O型圈可靠。

3. **2:1齿轮传动** — 紧凑齿比平衡推进应用中的扭矩和转速。

4. **多介质适配** — 为水下ROV设计，同等原理适用于：
   - 🌊 **水下** — ROV、AUV、水下机械手
   - 🚁 **空中** — 云台摄像头、万向节
   - 🤖 **陆地** — 机械臂、旋转关节
   - 🏭 **工业** — 旋转平台、线缆管理
